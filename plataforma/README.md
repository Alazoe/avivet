# Plataforma de bioseguridad

Página de acceso (`noindex`, no está en el sitemap) a las evaluaciones, que son independientes entre sí: Auditoría SAG, Riesgo del entorno del sector y Riesgo Influenza Aviar.
Para sumar una herramienta, agregar una línea a la lista `HERRAMIENTAS` al final de `index.html`.
